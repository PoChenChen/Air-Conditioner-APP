# Air AR - Android 圖片放置應用程式

這是一個基於 Android + CameraX 的專業圖片放置應用程式，允許使用者拍照並在照片上放置和調整多個圖片元素，支援完整的圖層管理系統和現代化的用戶界面。

## 🎯 功能特色

- 📸 **CameraX 拍照功能**：使用 CameraX 進行拍照，自動跳轉至圖片放置頁面
- 🖼️ **多圖層圖片放置**：支援在拍攝的照片上放置多個圖片元素
- 🎮 **高級圖片操作**：支援圖片的拖拽、縮放、旋轉、透明度調整
- 📚 **完整圖層管理**：支援圖層順序調整、複製、鎖定、可見性控制
- 🔄 **操作歷史**：支援撤銷/重做功能，安全操作
- 🎨 **背景處理**：支援背景圖旋轉和縮放，多種背景類型選擇
- 💾 **數據持久化**：使用 Room 數據庫保存圖片位置和屬性
- 🧭 **Compose Navigation**：多頁面導覽，流暢的用戶體驗
- 📱 **Material Design 3**：現代化的 UI 設計，專業外觀
- ⚡ **流暢動畫**：優化的圖片移動和縮放動畫效果
- 🎯 **多選圖層**：支援同時選擇多個圖層進行批量操作
- 🖼️ **預設圖片系統**：內建五種專業預設圖片（角度、角落、空調、管道等）
- 📐 **智能對齊**：支援圖層自動對齊到中線和邊界，精確定位
- 🎛️ **三重控制面板**：最小化、收起、展開三種狀態的浮動控制面板
- 📋 **分頁控制系統**：移動、變形、動作三個功能分頁，提升操作效率
- 🎯 **方向控制系統**：精確的方向按鈕控制，避免手勢拖拽卡頓
- 💾 **完整保存功能**：支援合成圖片保存和模型數據保存

## 🏗️ 技術架構

- **UI Framework**: Jetpack Compose
- **Navigation**: Compose Navigation
- **Image Processing**: Android ImageView + Compose Image + BitmapFactory
- **Camera**: CameraX
- **Database**: Room (支援多圖層數據結構，版本5)
- **Architecture**: MVVM with Repository Pattern
- **Language**: Kotlin
- **Design System**: Material Design 3
- **Animation**: Compose Animation with Spring and Tween
- **State Management**: StateFlow + Compose State
- **Image Loading**: 預設圖片資源 + 本地文件系統
- **Gesture Handling**: Compose Gesture Detection
- **File Management**: Android MediaStore + 私有目錄

## 📱 主要頁面

1. **主頁 (Home)**：應用程式入口，提供功能導覽
2. **相機頁面 (Camera)**：使用 CameraX 拍照
3. **背景選擇頁面 (Direct Placement)**：選擇背景圖類型
4. **圖片放置頁面 (Model Placement)**：在照片上放置和調整多個圖片
5. **模型列表頁面 (Model List)**：顯示所有已保存的圖片放置
6. **模型詳情頁面 (Model Detail)**：查看特定圖片放置的詳細信息和預覽

## 🚀 使用流程

### 1. 拍照並放置圖片
1. 點擊「拍照並放置模型」
2. 使用相機拍照
3. 自動跳轉至圖片放置頁面
4. 點擊「添加圖片」選擇預設圖片
5. 拖拽調整圖片位置（新增圖片會自動置中）
6. 使用滑塊調整縮放、旋轉和透明度
7. 使用圖層管理功能組織圖片
8. 使用撤銷/重做功能安全操作
9. 保存圖片放置

### 2. 直接放置圖片
1. 點擊「直接放置模型」
2. 選擇背景圖類型（透明、自定義）
3. 進入圖片放置頁面
4. 添加和調整圖片圖層
5. 保存圖片放置

### 3. 查看已保存的圖片放置
1. 點擊「查看已放置的模型」
2. 瀏覽圖片放置列表
3. 點擊查看詳情或刪除

## 🎮 圖片操作

### 基本操作
- **拖拽**：用手指拖拽圖片到任意位置（優化後的流暢動畫）
- **縮放**：使用滑塊調整圖片大小 (0.1x - 5x)
- **旋轉**：使用滑塊調整圖片旋轉角度 (0° - 360°)
- **透明度**：使用滑塊調整圖片透明度 (0.0 - 1.0)

### 高級操作
- **撤銷/重做**：使用頂部工具欄的撤銷/重做按鈕
- **圖層鎖定**：鎖定圖層防止意外移動
- **圖層可見性**：隱藏或顯示特定圖層
- **圖層複製**：一鍵複製現有圖層
- **重置**：一鍵重置圖片位置、縮放、旋轉和透明度
- **刪除**：刪除選中的圖片圖層

### 多選操作
- **多選圖層**：長按圖層進入多選模式，可同時選擇多個圖層
- **批量操作**：對選中的多個圖層進行批量移動、縮放、旋轉等操作
- **批量複製**：一鍵複製多個選中的圖層
- **批量刪除**：同時刪除多個選中的圖層

### 智能對齊
- **網格對齊**：圖層自動對齊到可調整的網格系統
- **精確定位**：避免手動拖拽的偏差，提供精確的圖層定位
- **可調網格**：支援調整網格大小，適應不同的設計需求

## 📚 圖層管理

### 圖層操作
- **添加圖層**：點擊「添加圖片」按鈕添加新的圖片圖層
- **選擇圖層**：點擊圖片或使用圖層管理器選擇圖層
- **調整圖層**：選中圖層後可以調整其屬性
- **刪除圖層**：在圖層控制面板中刪除選中的圖層

### 圖層順序控制
- **上移/下移**：調整圖層在堆疊中的位置
- **移到頂部**：將圖層移到最前面
- **移到底部**：將圖層移到最後面
- **自動排序**：圖層按 zIndex 自動排序顯示

### 圖層狀態管理
- **鎖定/解鎖**：防止圖層被意外移動
- **顯示/隱藏**：控制圖層的可見性
- **複製圖層**：快速複製現有圖層

## 🎨 背景處理

### 背景類型
- **拍照背景**：使用相機拍攝的照片作為背景
- **透明背景**：透明背景
- **自定義背景**：選擇設備中的圖片作為背景

### 背景旋轉
- **0度**：正常方向
- **90度**：順時針旋轉90度
- **180度**：旋轉180度
- **270度**：順時針旋轉270度

### 背景縮放
- **縮放範圍**：0.1x - 3x
- **即時預覽**：所有調整即時預覽效果
- **統一控制**：背景旋轉和縮放統一控制面板

## 💾 數據結構

每個圖片放置包含以下信息：
- **模型基本信息**：名稱、照片路徑、創建時間、背景旋轉角度
- **多個圖片圖層**，每個圖層包含：
  - 圖片路徑
  - 位置 (x, y)
  - 縮放比例
  - 旋轉角度
  - 透明度
  - 圖層順序 (zIndex)
  - 圖層名稱
  - 鎖定狀態
  - 可見性狀態
